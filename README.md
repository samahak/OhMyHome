# OhMyHome — 도면 위에 우리집 가구 배치해 보기

집 도면 이미지를 넣으면 실제 크기(mm)로 맞춰 벽을 세우고, 냉장고·세탁기·붙박이장·침대 같은 가구를
2D 도면과 3D 화면에서 끌어다 놓아 볼 수 있는 웹 페이지입니다. 빌드 과정 없이 정적 파일만으로 돕니다.

## 실행

```bash
./run_ohmyhome.sh   # macOS / Linux → http://localhost:8190  (PORT=9000 ./run_ohmyhome.sh 로 포트 변경)
run_ohmyhome.bat    # Windows
```

ES 모듈을 쓰므로 `index.html`을 더블클릭(file://)으로 열면 동작하지 않습니다. 반드시 웹 서버로 여세요.
3D 라이브러리(three.js 0.160)는 CDN에서 받으므로 인터넷 연결이 필요합니다.

## 사용 순서

1. **① 도면** — `도면 이미지 열기`(PNG·JPG) 또는 `샘플 도면으로 해 보기`
2. **축척 맞추기** — `📏 두 점을 찍고 실제 길이 입력`으로 도면의 치수선 양 끝을 찍고 실제 길이(mm)를 넣습니다.
   도면 전체 가로 길이를 알면 바로 입력해도 됩니다.
3. **벽 세우기** — `벽 인식 실행`으로 굵은 벽을 자동으로 찾습니다. 색이 있는 도면은 `벽 색 찍기`로 벽을 한 번 누르세요.
   빠진 벽은 `🧱 벽 그리기`, 잘못 잡힌 벽은 `🧽 지우기`로 고칩니다.
4. **방 면적** — `⬛ 방 영역`으로 꼭짓점을 찍으면 ㎡·평과 가로×세로가 나옵니다. `📐 길이 재기`로 임의의 두 점 거리도 잽니다.
5. **② 가구** — 샘플 가구를 누르면 화면 가운데의 빈자리에 놓입니다. 2D·3D 어디서든 끌어서 옮깁니다.
6. **사진으로 가구 추가** — 가구 정면 사진을 넣으면 가구 영역을 자동으로 찾습니다(초록 상자, 직접 조정 가능).
   - 아는 치수 하나(제품 스펙의 가로 또는 높이)를 넣으면 비율로 나머지를 계산합니다.
   - 또는 사진 속 기준 물체(A4 용지·신용카드 등)에 기준선을 그어 가로·높이를 함께 잽니다.
   - 깊이는 정면 사진으로 알 수 없어 고른 샘플 모양의 기본값을 쓰고, 고칠 수 있습니다.
   - 샘플 모양(냉장고·세탁기·붙박이장·침대…)을 고르면 그 모양으로 3D에 그리고, 사진을 앞면에 입힐 수 있습니다.

벽이나 다른 가구와 겹치는 가구는 빨갛게 표시됩니다. `🧲 벽에 붙이기`는 가장 가까운 벽에 등을 대고 붙입니다.

## 샘플 도면 (`sample/`)

| 파일 | 내용 |
| --- | --- |
| `55A2_plan_2d.png` | 55㎡ A-2형(확장형) 2D 평면도 — 바깥 치수 체인과 방마다 가로×세로(벽 안쪽, mm) |
| `55A2_plan_3d.png` | 같은 도면을 이 앱으로 세운 3D 화면 (벽 낮게 보기) |
| `55A2_plan.ohmyhome.json` | 앱 상단 `불러오기`로 바로 여는 프로젝트 (축척 1px = 5mm, 벽 입력 완료) |

`55A2_plan_2d.png`를 `도면 이미지 열기`로 넣어도 됩니다. 치수 도구로 거실을 누르고 3,600으로 맞추면 됩니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `R` / `Shift+R` | 선택한 가구 90° 회전 |
| `Q` / `E` | 15° 회전 |
| 방향키 (`Shift`) | 10mm (100mm) 이동 |
| `Delete` | 선택 삭제 |
| `Ctrl/⌘+Z`, `Ctrl/⌘+Shift+Z` | 되돌리기 / 다시 하기 |
| `Ctrl/⌘+D` | 복제 |
| `V` `W` `A` `M` `X` | 선택 · 벽 · 방 · 길이 재기 · 지우기 도구 |
| `F` | 2D 도면 전체 보기 |
| `Esc` | 그리던 것 취소 / 선택 해제 |

2D 화면: 휠로 확대·축소, 빈 곳·오른쪽·가운데 버튼 드래그(또는 Space+드래그)로 이동.
3D 화면: 드래그로 회전, 오른쪽 드래그로 이동, 휠로 확대·축소.

## 저장

작업은 브라우저(localStorage)에 자동 저장됩니다. 다른 컴퓨터로 옮기거나 보관하려면 상단 `저장(.json)` /
`불러오기`를 쓰세요. 도면 이미지와 가구 사진도 파일 안에 함께 들어갑니다. `3D 캡처`는 지금 3D 화면을 PNG로 받습니다.

## 구조

```
index.html            화면 뼈대 (three.js는 importmap으로 CDN에서)
css/style.css
js/main.js            화면 조립 · 패널 · 단축키
js/store.js           상태 · 이벤트 · 되돌리기 · 자동 저장
js/geometry.js        평면 기하 (겹침 판정, 벽에 붙이기, 면적)
js/plan2d.js          2D 도면 편집기 (캔버스)
js/view3d.js          3D 보기 · 가구 끌기 (three.js)
js/models3d.js        샘플 가구 3D 모양
js/catalog.js         샘플 가구 목록 · 기본 크기 · 모양 추천
js/wallDetect.js      도면 이미지 → 벽 사각형 (DOM 없이 동작)
js/furniturePhoto.js  가구 사진 → 크기 측정
js/samplePlan.js      체험용 샘플 도면
```

좌표는 모두 mm이고 도면 이미지처럼 y가 아래로 커집니다. 3D에서는 x → x, y → z 로 놓고 m 단위로 바꿉니다.

## 한계

- 도면의 치수 숫자를 글자 인식(OCR)으로 읽지는 않습니다. 축척은 사용자가 두 점과 길이로 한 번 맞춥니다.
- 벽 자동 인식은 축에 나란한(가로·세로) 벽을 찾습니다. 사선 벽은 직접 그리세요.
- 사진 한 장으로 잰 크기는 원근 때문에 어림값입니다. 제품 스펙이 있으면 그 값을 넣는 것이 가장 정확합니다.
