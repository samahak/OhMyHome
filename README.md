# OhMyHome — 도면 위에 우리집 가구 배치해 보기

집 도면 이미지를 넣으면 실제 크기(mm)로 맞춰 벽을 세우고, 냉장고·세탁기·붙박이장·침대 같은 가구를
2D 도면과 3D 화면에서 끌어다 놓아 볼 수 있는 웹 페이지입니다. 빌드 과정 없이 정적 파일만으로 돕니다.

## 실행

```bash
./run_ohmyhome.sh   # macOS / Linux → http://localhost:8190  (PORT=9000 ./run_ohmyhome.sh 로 포트 변경)
run_ohmyhome.bat    # Windows
```

기본은 이 PC에서만 열립니다. 같은 와이파이의 휴대폰·다른 PC에서 열려면 `HOST=0.0.0.0 ./run_ohmyhome.sh`
(Windows는 `set HOST=0.0.0.0` 뒤 `run_ohmyhome.bat`)로 띄우고, 화면에 찍히는 `http://<내 PC IP>:8190`으로 접속합니다.
작업 내용은 프로젝트 폴더의 `ohmyhome-project.json`에 저장되므로 localhost · IP 어느 주소, 어느 기기로 열어도 같은 작업이 보입니다.

배포용 zip은 `./build_ohmyhome.sh`(Windows는 `build_ohmyhome.bat`)로 `dist/OhMyHome-<날짜>.zip`에 만듭니다.
화면 파일·실행 스크립트·`sample/plan`·`sample/real`의 json·사용 가이드 PDF(`docs/OhMyHome_Guide.pdf`, 공지사항 창이 내려받게 하는
`docs/OhMyHome_User_Guide.pdf`)·A1-real·A2-real·B1-real 실측 기록지(`measure/55A1_measured.pdf` · `55A2_measured.pdf` · `55B1_measured.pdf`)만 담고, 이 README와
브라우저에 저장된 내 작업은 들어가지 않습니다. 가이드를 고치면 `docs/guide/make_pdf.sh`로 PDF를 다시 만드세요.

ES 모듈을 쓰므로 `index.html`을 더블클릭(file://)으로 열면 동작하지 않습니다. 반드시 웹 서버로 여세요.
3D 라이브러리(three.js 0.160)는 CDN에서 받으므로 인터넷 연결이 필요합니다.

## 사용 순서

처음 접속하면 프로그램 소개와 사용 가이드(PDF) 내려받기가 있는 **공지사항** 창이 뜹니다. 창 아래 `다시 보지 않기`에 체크해 두면 그 브라우저에서는 접속할 때 저절로 뜨지 않고, 위쪽 `📢 공지사항`으로 열어 체크를 풀면 다음 접속부터 다시 뜹니다.
언제든 위쪽 `📢 공지사항` 버튼으로 다시 볼 수 있고, 공지가 바뀐 뒤 7일 동안 그 공지를 아직 읽지 않았으면 버튼에 **NEW**가 붙습니다(한 번 읽으면 그 브라우저에서는 사라지고, 공지가 또 바뀌면 다시 붙습니다).

1. **① 도면** — `Xi 위례자이더파크 불러오기`로 `sample/`의 예시 세대 도면을 골라 열거나(창에서 형을 고르고 `불러오기`, A1-real·A2-real·B1-real 줄의 `📄 실측 기록지`로 실측 기록지 PDF 내려받기),
   `📂 도면 불러오기(json)`로 저장해 둔 도면 파일(`저장(.json)`으로 받은 것)을 열거나 `샘플 도면으로 해 보기`.
   도면 이름은 상단 되돌리기 왼쪽에 보이고 눌러서 고칠 수 있습니다. `저장(.json)` 파일 이름은 `ohmyhome-{도면이름}-{날짜}.json`입니다.
   평면도 그림(PNG·JPG)을 새로 넣는 기능은 없습니다. 아래 2·3은 연 도면의 크기·벽을 고칠 때 씁니다.
   같은 집 도면이 조금 고쳐졌을 때는 `🔁 도면만 바꾸기(json)` — 경고를 한 번 띄운 뒤 벽·방·창·문·도면 그림만 바꾸고 가구 배치는 그대로 둡니다(싱크대가 없는 배치에는 그 도면의 싱크대 — A2-real이면 ㄱ자 — 를 바로 놓습니다).
2. **축척 맞추기** — `📏 두 점을 찍고 실제 길이 입력`으로 도면의 치수선 양 끝을 찍고 실제 길이(mm)를 넣습니다.
   도면 전체 가로 길이를 알면 바로 입력해도 됩니다.
3. **벽 세우기** — `벽 인식 실행`으로 굵은 벽을 자동으로 찾습니다. 색이 있는 도면은 `벽 색 찍기`로 벽을 한 번 누르세요.
   빠진 벽은 `🧱 벽 그리기`, 잘못 잡힌 벽은 `🧽 지우기`로 고칩니다.
4. **방 면적** — `⬛ 방 영역`으로 꼭짓점을 찍으면 ㎡·평과 가로×세로가 나옵니다. `📐 길이 재기`로 임의의 두 점 거리도 잽니다.
   **창** — 도면에서 벽 위에 연하게 그려진 창 자리와 바깥벽의 틈은 자동으로 창이 됩니다. `🪟 창문` 도구로 벽을 누르면 직접 낼 수 있고,
   창을 골라 폭·바닥에서 창 아래 높이·창 높이를 바꿉니다(허리창 / 바닥까지 큰 창).
   **문** — 벽 인식 때(또는 `🚪 문 기호 찾아 문 달기`) 도면에 여닫이 문 기호(문짝 선 + 호)나 미서기 문 기호(틈 안에 엇갈린 두 선)가 그려진 틈마다 문을 답니다.
   3D에서는 문 위를 천장까지 벽으로 채우고 문짝을 도면대로 열어 둡니다. `🚪 문` 도구로 틈을 누르면 직접 달고,
   문을 골라 경첩·여는 쪽을 바꿉니다. 문을 고르면 `여닫이` · `양여닫이` · `미닫이` · `미서기` · `중문` 모양을 바꿀 수 있고(양여닫이는 양 끝 경첩의 두 짝이 옷장 문처럼 같은 쪽으로 열림, 미닫이는 1.3m 넘는 틈이면 두 짝이 양쪽으로 열림,
   미서기는 벽 두께 안의 두 짝이 엇갈려 옆으로 밀림), 🚪 문 도구로 새로 다는 문은 마지막에 고른 모양이 됩니다. 벽 면 밖에 붙는 미닫이 기호는 자동으로 찾지 않습니다.
   `현관 중문`은 현관문 안쪽(현관 방 영역의 가장자리) 틈에 유리 3연동 중문을 답니다. 문 위는 천장까지 고정 유리입니다.
   중문은 2D에서 끌거나 속성의 `현관문에서 (mm)`를 고쳐 양옆 벽을 따라 앞뒤로만 옮길 수 있습니다(폭은 양옆 벽에 맞춤).
5. **② 가구** — 샘플 가구를 누르면 화면 가운데의 빈자리에 놓입니다. 2D·3D 어디서든 끌어서 옮깁니다.
   벽걸이 TV·월패드는 바닥에서 띄워 놓이니(월패드 1.3m) `🧲 벽에 붙이기`로 벽에 답니다. `전열교환기`(환기 장치)는 천장에 매달린 채(2,030 띄움 — 위가 천장 2,300) 놓입니다. `벽등`을 놓은 방은 둘러보기에서 천장 방등 대신 그 벽등이 방을 밝힙니다(위례자이더파크 A형 실외기실은 문 들어가서 오른쪽 벽의 벽등).
   `전자레인지 장`은 아래 수납 · 전자레인지 칸 · 밥솥 칸 · 위 수납이 있는 키큰 렌지대(600×450×1,800mm)입니다.
   `커튼`은 레일 + 양옆 주름 커튼 + 가운데 반투명 속커튼이고, 창 앞 벽에 `🧲 벽에 붙이기`로 답니다(색은 겉 커튼 천 색). 커튼은 다른 가구와 겹쳐 놓아도 됩니다.
   `커튼 봉`은 벽과 벽 사이에 거는 봉입니다(드레스룸·다용도실 입구 가림막 등). 벽 사이로 끌어 놓으면 양쪽 벽까지 길이가 저절로 맞춰지고(⟳ 90°로 방향을 바꾸면 그 방향 벽 사이로),
   속성에서 커튼을 `양옆으로 걷음` · `쳐 둠` · `봉만`으로 고르며, 높이 H가 봉 높이입니다. 가로를 직접 고치면 그 길이를 지킵니다.
   `선반장`은 아래 문 두 짝 수납장 + 위 트인 선반 칸(800×400×1,800mm), `샤워부스`는 받침 + 앞·양옆 유리 + 샤워 수전(900×900×2,000mm, 색은 틀 색)입니다.
   `Shift+클릭`(2D에서는 빈 곳 `Shift+끌기`도)으로 여러 개를 골라 함께 옮기고·돌리고·복제·삭제합니다.
   왼쪽 `배치된 가구` 목록은 종류별(침대·소파·의자…)로 묶여 보입니다.
   `식물`(🪴)은 놓은 뒤 속성에서 종류(몬스테라·여인초·올리브나무·고무나무·아레카야자·산세베리아·금전수·스킨답서스)를 고르면 모양·크기가 바뀝니다.
   붙박이장·옷장은 속성의 `옷장 모양`(통·분리형·2단 서랍형·3단 서랍형·믹스장·냉장고장, 기본은 통 — 믹스장은 약 90cm 칸마다 통·분리형·서랍형을 따로 고름)과 `문 없음`(칸·선반·옷걸이 봉이 보이는 오픈형)을 고릅니다. 냉장고장은 위 짧은 장만 있고 아래가 바닥까지 트여 있어 냉장고·김치냉장고를 겹쳐 넣어도 겹침으로 잡히지 않습니다.
   `정수기`(💧)는 바닥에 단독으로 두면 대형(스탠드형), 주방 싱크대 위로 끌어다 놓으면 소형 정수기로 바뀌어 상판 위에 올라갑니다.
   의자는 `등받이 없음`에 체크하면 엉덩이만 앉는 스툴이 되어(샘플 `스툴`도 있음) 책상·식탁 밑으로 통째로 들어갑니다.
   가구마다 `모델명`·`가격`을 넣으면 목록 위에 전체 합계, 종류 제목에 소계가 나옵니다(`129만`·`1,290,000` 모두 됨).
   집에 딸려 오는 가구는 `기본 포함 가구`에 체크하면 2D 도면에 빗금으로 다른 가구 뒤에 보이고 합계에서 빠집니다(겹친 곳을 누르면 기본 포함이 아닌 가구가 먼저 골라집니다)(여러 개를 골라 한꺼번에 바꿀 수도 있습니다).
   잠시 빼 둘 가구는 `비활성화`에 체크하면 지우지 않고 점선·연한 색으로 남고, 겹침·둘러보기 길·합계에서 빠집니다.
   기성품이 아니라 따로 만드는 가구는 `🛠️ 맞춤 제작`에 체크하면 도면의 치수 아래와 목록에 `🛠️ 맞춤` 꼬리표가 붙고, 엑셀 '구분'에 '맞춤 제작'으로 나옵니다.
   현관 중문(그리고 가격을 넣은 문)도 문을 골라 모델명·가격을 넣으면 합계와 목록 맨 아래 `🚪 문` 묶음에 들어갑니다.
   `📊 엑셀로 내보내기`는 가격이 계산된 가구(·문) 목록과 합계를 엑셀(.xlsx)로 받습니다. `모든 가구`를 켜면 가격 없는 가구까지 넣고, 기본 가구는 합계 아래에 따로 모읍니다.
   `ㄱ자 주방 싱크대`는 가로(뒤쪽)·세로(꺾인 쪽) 길이와 상판 깊이를 고치고, `⇋ 좌우 반전`으로 꺾인 쪽을 바꿉니다.
   개수대 → 인덕션은 가로 쪽에, 꺾인 쪽은 선반이고 상부장은 ㄱ자로 이어집니다. 꺾인 쪽만 더 깊으면 `꺾인 쪽 깊이`를 따로 넣습니다(예: 조리대 600 · 선반 740).
   `욕실 상부 선반`은 바닥에서 1.5m 위 벽에 거는 선반이라 `욕실 철제 선반`과 겹쳐 놓을 수 있습니다. `신발장`은 위아래가 한 번에 열리는 통문짝입니다.
   가운데 위 `⛶ 전체 화면`(둘러보기 왼쪽)은 지금 보기(2D 도면·나란히·3D) 그대로 화면 전체에 띄우고, 오른쪽 위 `⤢ 맞추기`로 2D·3D를 화면 크기에 맞춰 도면 전체가 보이게 하고, `📷 캡처`로 보이는 그대로 그림(PNG)을 저장하며, `✕ 닫기`나 Esc로 돌아옵니다.
6. **🚶 둘러보기** — 현관 앞에서 문을 열고 들어가 방들을 차례로 돌아봅니다(현관문은 두꺼운 철문(번호 키 도어록·도어 렌즈·도어 클로저)이고 밖(공용 홀)으로 열립니다.). 처음 한 번은 2D 도면에서 현관문 자리를
   누르면 됩니다. 현관을 한 번 둘러본 뒤, 방문 너머 방(욕실·드레스룸·실외기실 포함)은 모두 들어가 보고 거실·주방은 한 번씩 둘러봅니다.
   방 이름은 `⬛ 방 영역`으로 그린 방 이름을 쓰고, 없으면 그 방 가구로 짐작합니다(침대 → 침실, 변기 → 욕실 …, 모르면 '방').
   집 안에 들어오면 현관문·방문 문짝은 투명하게 모양(테두리 선)만 보여 문 너머 방 안이 다 보입니다.
   둘러보기 중에는 편집 화면(왼쪽·오른쪽 패널, 도면 이름·되돌리기·새 프로젝트, 2D·3D 보기 막대)이 잠겨 눌리지 않습니다. 안내판의 ✕ 나가기(Esc)로 나오면 다시 편집할 수 있습니다(저장·캡처는 둘러보기 중에도 됩니다).
   현관에는 신발장을, 욕실·주방 이름이 붙은 방에는 변기·세면대·욕조·주방 싱크대(인덕션 포함 — 도면 파일에 기본 싱크대가 있으면 그것, A1-real·A2-real은 ㄱ자)를 자동으로 놓고
   (가구 목록에서 옮기거나 지울 수 있음), 현관(신발 벗는 곳)과 욕실은 바닥을 한 단 낮춰 회색 타일로 보여 주며,
   거실 천장은 우물형(간접조명 — 방 이름이 없으면 도면 아래쪽에서 가로가 가장 넓은 공간을 거실로 봅니다), 다른 방은 천장 가운데 네모난 LED 방등으로, 창은 창틀·유리로 창밖 하늘이 보이게 보여 줍니다.
   `층수`(그리기 도구 카드)를 정하면 그 높이에서 창밖으로 앞 도로·차·가로수, 길 건너 빌라, 주변 아파트, 시가지의 숲·공원, 나무가 빽빽한 먼 산이 보입니다.
   둘러보는 중에도 화면을 끌어 고개를 돌리고, W/S·↑↓로 걷고, A/D로 옆걸음, ←→로 돌 수 있습니다. Space 멈춤/계속, N 다음 곳, F(또는 `⛶ 전체 화면`) 3D 칸을 화면 가득, Esc 나가기(전체 화면이면 전체 화면만 끄기).

벽이나 다른 가구, 도면의 빗금 칸(샤프트 등 — 2D에 점선 테두리의 회색 빗금으로 보이는 배치 금지 구역)과 겹치는 가구는 빨갛게 표시됩니다. `🧲 벽에 붙이기`는 가장 가까운 벽에 등을 대고 붙입니다.

## 저장

`run_ohmyhome`(serve.py)로 열면 작업이 **프로젝트 폴더의 `ohmyhome-project.json`** 에 자동 저장되고, 열 때도 이 파일을 먼저 읽습니다.
그래서 localhost · 127.0.0.1 · 내 PC IP 어느 주소로 열어도 같은 작업이 보입니다(다른 기기에서 고쳤으면 새로 고침).
브라우저(localStorage, 주소마다 따로)에도 예비로 함께 저장합니다. 다른 컴퓨터로 옮기거나 보관하려면 상단 `저장(.json)`으로 받고
왼쪽 `📂 도면 불러오기(json)`로 여세요.
가구 배치는 `② 가구` 탭 맨 위 **배치 안**에서 1안 · 2안 · 3안…으로 여러 개 둘 수 있습니다. `＋ 지금 안 복사해서 추가`는 보고 있는 안을
그대로 복사해 새 안을 만들고, 안을 누르면 바꿔 봅니다(도면·문은 모든 안이 함께 씁니다). 마음에 드는 안은 `🔓 보호하기`로 잠가 두면
가구를 옮기거나 고치거나 지울 수 없습니다(다시 누르면 풉니다. 보호 중인 안은 지울 수 없고, 복사해 만든 새 안은 고칠 수 있습니다). 엑셀·캡처 파일 이름에 안 이름이 붙습니다. 도면 이미지도 파일 안에 함께 들어갑니다. `2D 캡처`·`3D 캡처`는 PDF 한 파일로 받습니다. 2D는 도면 전체 1쪽 + 제목·설명·바깥 치수를 뺀 집 부분만 크게 1쪽, 3D는 위에서 · 왼쪽 비스듬히 · 오른쪽 비스듬히를 바닥 도면 그림과 함께 3쪽 + 도면 그림을 뺀 집만 3쪽입니다(둘러보기 중에는 지금 화면 1쪽). 집이 세로로 길면 그 쪽은 세로 A4입니다.
